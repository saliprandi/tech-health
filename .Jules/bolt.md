## 2026-03-31 - Asynchronous Google Fonts Loading to Eliminate Critical Path Blocking
**Learning:** Standard `<link rel="stylesheet">` tags for Google Fonts in Astro HTML head block page parsing and critical rendering path until CSS download completes. Replacing them with `<link rel="preload" as="style">` and `<link rel="stylesheet" media="print" onload="this.setAttribute('media', 'all')">` (with a `<noscript>` fallback) allows fonts to load asynchronously in parallel without blocking initial paint, improving LCP and FCP metrics while maintaining zero TypeScript diagnostic warnings in Astro checks.
**Action:** Always use non-render-blocking `<link rel="preload">` + `<link rel="stylesheet" media="print" onload="this.setAttribute('media', 'all')">` pattern for external font stylesheets in Astro layouts.
