## 2026-03-30 - Accordion O(1) Active Element Tracking in Astro Client Scripts
**Learning:** In accordion components like `FAQ.astro`, iterating over all `.faq-item` elements with `querySelectorAll` and `querySelector` on every toggle event executes $O(N)$ DOM query operations. Storing references to the currently active trigger, container, and icon in the component's initialization function closure scope enables $O(1)$ constant-time closing of the previous item without iterating over the DOM tree, while ensuring state encapsulation across page swaps (`astro:after-swap`).
**Action:** When writing accordion or tab components in Astro/vanilla JS, track active element references inside the component initialization function scope to achieve $O(1)$ state updates on click events.
