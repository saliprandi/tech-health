## 2025-05-15 - Accessible Modal Pattern for Astro Components
**Learning:** Standard Astro components often use "clickable divs" for interaction, which are inaccessible to keyboard and screen reader users. Implementing a full accessibility lifecycle (role="button", tabindex="0", focus trapping, and focus restoration) is critical for these custom UI elements. Using `invisible` class alongside `opacity-0` ensures that hidden modals are not interactable or perceivable by assistive technologies while animations are pending or finished.
**Action:** Always verify custom interactive elements for keyboard accessibility. Apply `role="button"` and `tabindex="0"` to interactive containers, and ensure modals manage focus strictly by trapping it within the dialog and restoring it to the trigger upon closure.
